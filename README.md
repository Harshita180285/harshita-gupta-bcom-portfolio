# Harshita Gupta — Professional Portfolio

A responsive static portfolio website for Harshita Gupta, B.Com (FinTech & AI), Lovely Professional University.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Before publishing
1. Replace the LinkedIn placeholder in `index.html` with the real LinkedIn URL.
2. Replace `your-email@example.com` with the preferred email address.
3. Add project/certificate links later when available.

## Deploy on Vercel
This is a static website, so no build command is required.

- Framework preset: Other
- Build command: leave blank
- Output directory: `.`
- Root directory: project root

## GitHub
Create a repository, upload all files/folders, then import that repository into Vercel.
